## 🐛 Common First-Time Issues

### Issue 1: AI Not Working
**Solution**: 
```powershell
$env:GOOGLE_API_KEY="your_key"
```

### Issue 2: PDF Not Generating
**Solution**: Install wkhtmltopdf or use HTML download

### Issue 3: Blank ATS Score
**Solution**: Ensure job description is pasted, resume has content

### Issue 4: Page Not Loading
**Solution**: 
```powershell
streamlit cache clear
streamlit run app.py
```
