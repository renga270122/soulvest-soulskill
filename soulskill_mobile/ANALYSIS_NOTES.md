# Flutter reconstruction notes

- The previous soulskill_mobile/lib/ and soulskill_mobile/android/ directories are absent from the repository tree and were not found in the searched path-specific Git history.
- This is a new baseline, not a restoration of the old UI.
- The app currently stores one resume draft locally on the device.
- The AI summary action calls POST /api/ai/improve-summary on the existing api_server.py service. This endpoint is unauthenticated in the current server; keep it for development only until the API authentication work item is completed.
- The resume model serializes to the mobile API ResumeData field names, but cloud resume save/load is intentionally not wired because the current mobile API save endpoint writes timestamped JSON files and has no user-owned load/update/delete workflow.
- Android native files are generated by Flutter CLI from scripts/bootstrap_android.sh; they are not hand-written or represented as already build-tested.
- No Android APK build has been performed by the GitHub connector environment. Run the documented Flutter quality checks in a local Flutter SDK or CI before release.
