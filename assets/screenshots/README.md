# Soulvest Screenshots

This directory contains screenshots for PWA app store listings and social media sharing.

## Required Screenshots

### For PWA Manifest:
1. **Desktop Screenshot** (desktop.png)
   - Dimensions: 1280x720 or 1920x1080
   - Shows the main resume builder interface
   - Wide format

2. **Mobile Screenshot** (mobile.png)
   - Dimensions: 750x1334 (iPhone) or 1080x1920 (Android)
   - Shows mobile-optimized view
   - Narrow format

### For Social Media:
3. **Open Graph Image** (og-image.png)
   - Dimensions: 1200x630
   - Used for Facebook, LinkedIn sharing
   - Include branding and key features

4. **Twitter Card** (twitter-card.png)
   - Dimensions: 1200x675 (or 1200x630)
   - Used for Twitter sharing
   - Similar to OG image

## How to Create Screenshots

### Desktop Screenshot:
1. Open app in browser at full width (1920px+)
2. Navigate to resume builder main page
3. Take screenshot (Windows: Win+Shift+S)
4. Crop to 1280x720 or 1920x1080
5. Save as desktop.png

### Mobile Screenshot:
1. Open Chrome DevTools (F12)
2. Toggle device toolbar (Ctrl+Shift+M)
3. Select iPhone or Galaxy device
4. Take screenshot in DevTools
5. Save as mobile.png

### Social Media Images:
1. Use Canva, Figma, or Photoshop
2. Create 1200x630 canvas
3. Add:
   - Soulvest logo/branding
   - Key features (AI-powered, ATS-optimized)
   - Visual appeal (gradient, mockups)
   - Call to action
4. Export as PNG

## Design Guidelines

### Content to Show:
- ✅ Resume builder interface
- ✅ Soulvest branding/logo
- ✅ Key features visible
- ✅ Professional, clean design
- ✅ High quality, no blur

### Avoid:
- ❌ Personal information (use dummy data)
- ❌ Low resolution
- ❌ Clutter or too much text
- ❌ Dark/hard to read elements
